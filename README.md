## 🔥 Project Overview

**This tool** is a comprehensive trainer for **BOMBANANA!**. This trainer provides optional control over bomb-defusal sessions, including the countdown timer, explosion state, allowed mistakes, puzzle modules, and environmental hazards. It is designed to make campaign, endless, and custom challenges easier to practice or complete.

**Target Audience:** Players who want to practice bomb modules, learn the three asymmetric roles, reduce time pressure, or enjoy campaign, endless, and custom levels with a more forgiving difficulty.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Freeze Bomb Timer** — Pauses the active bomb countdown so the team can inspect modules and coordinate without time pressure.
- **Prevent Explosion** — Stops the bomb from detonating when the countdown reaches zero or a failure condition is triggered.
- **Disable Environmental Hazards** — Suppresses disruptive events such as power outages, obstructions, and loud interruptions.
- **Session Completion Assist** — Helps the team finish the current bomb-defusal challenge without changing the game's core three-player structure.

### 📌 Puzzle

- **Unlimited Mistakes** — Prevents incorrect interactions from consuming the session's allowed mistakes.
- **Reveal Puzzle Modules** — Highlights active bomb modules and their current state for easier practice and troubleshooting.

## 📖 Detailed Feature Guide

### Movement & Exploration

Movement is used to navigate the level, approach the bomb, observe teammates, and respond to environmental hazards. The trainer does not replace movement or communication; use the timer and hazard options to create a calmer practice environment.

### Tools & Inventory

BOMBANANA! does not use a conventional inventory system. Progress depends on interacting with bomb modules, reading the manual, observing visual information, and communicating between the three roles.

### World & Environment

The game features bomb-defusal environments including the minivan and other challenge locations. Campaign levels are handcrafted, endless mode uses progressively harder procedural waves, and custom mode allows players to adjust difficulty, timers, modules, hazards, and mistakes.

### Combat & Weapons

BOMBANANA! has no conventional combat system. Its core challenge is non-violent bomb disposal through cooperation, asymmetric information, gestures, voice chat, and puzzle solving.
